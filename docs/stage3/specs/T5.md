## 1. Goal and dependencies

- Goal: Riley's side of the cutthroat grab. A held Riley plays `riley_grabbed` (loop), routes mash presses to the
  grabber, ignores everything but hazards, and on escape plays `riley_escape` (4 frames, shove beat on frame 1) before
  returning to `idle`. Stages 1 and 2 never reach these states.
- **T1 (landed, `e46f251`):** `STAGE_CHARS[3]` (`src/stages.js:45`) includes `riley3`, and `create()` builds anims with
  `this.metas = makeCharAnims(this, this.stageDef.chars)` (`src/stage1.js:142`), so `riley_grabbed` / `riley_escape`
  exist once the `riley3` meta is cached. Stage 3 is reachable only via `resolveStage` (`src/stages.js:35-39`) with
  `s3=1` (`stageEnabled`, `:12-16`, reading `q` from `src/config.js:5`).
- **T2:** `assets/stage3/chars/riley3.anims.json` + `riley3-0.{webp,json}` / `_n` / `_nl` (`"dir":
  "assets/stage3/chars"`, anim prefix `riley_`, frame names `riley3_*`). Canvas 960×640, baseline 610, scale 0.85:
  the **same** geometry as `assets/chars/riley.anims.json:3-8`, so `Fighter`'s origin/scale (`src/fighter.js:8-11`,
  computed once from `riley.anims.json`) stay correct for `riley3` frames.
- **T3:** `queueStage3` loads the `riley3` `.A` JSON and pages in the browser (T3 §3.3). T5 adds no loader code.
- **T4 (hard):**
  - **Riley contract** (T4 §3.4): the cutthroat owns `R.grabbedBy` (sets it in `startHold`, clears it only in
    `releaseHold`) and calls `R.enterGrabbed?.(c)` / `R.leaveGrabbed?.(how)` with `how ∈ 'escape' | 'throw' |
    'break'`. T5 calls `R.grabbedBy.mash()` once per counted press; it returns `true` on escape. T5 never clears
    `grabbedBy` itself.
  - **Mash contract** (T4 §3.1, §3.3, §9.4): `CUTTHROAT.mashNeed = 6`, `mashDecay = 0.5`. `mash()` does `mashN++`
    and **does not reset `mashT`**. `holding(dt)` decays unconditionally: `mashT += dt; while (mashT >= 0.5) {
    mashT -= 0.5; mashN = max(0, mashN - 1); }`. Decay ticks are aligned to the hold start (`startHold` sets
    `mashN = mashT = chips = 0`), at hold time 0.5, 1.0, 1.5, 2.0 s. Net effect, verbatim from T4: **escape needs 6
    presses inside one 0.5 s decay window, or sustained mashing of about 5 presses/s (0.2 s rhythm escapes at
    ≈1.8 s); 1 press per 0.45 s never gets past 1.**
  - **Chip** is counted (`chips`, `chipMax: 3`, at 0.6/1.2/1.8 s, floored at hp 1); there is **no `chipT`**.
    Timeout throw at `holdMax: 2.4` (8 dmg, knockdown) via `releaseHold('throw')` then `s.hitTarget(this, R, throwHit)`.
  - **Guards already in T4:** the `resolveAttack` skip (T4 §4.5, `src/stage1.js:364`), the hold break check (T4 §3.3
    step 1: `!R.alive`, `R.grabbedBy !== this`, Riley `hurt/down/getup/dead`, victory), `releaseHold` bumping
    `stats.breaks` only on a real release (T4 §3.3, resolves the old T5 §8.7), and the body-block skip for
    `holding` (T4 §4.6, `:687`).
  - **Harness:** `tests/helpers/stage3-harness.mjs` exports `stage3Simulation`, `arena`, `placeC`, `withSeed`,
    `FULL_STAGE_SEEDS` (T4 §7.1). `arena()` sets `s.god = true`.

### 3.4 New methods (insert after `throwing`, `:143-151`, before `takeHit`, `:153`)
```js
/** T4 contract: a cutthroat caught him (it already set grabbedBy, facing and vx) */
enterGrabbed(c) {
  this.lastGrabber = c; this.atk = null; this.next = false; this.kicked = false; this.vx = 0;
  this.mashDir = `${this.scene.inp?.x || 0},${this.scene.inp?.y || 0}`;   // a direction already held is not "new"
  this.setState('grabbed', 'grabbed');
}
/** T4 contract: the hold ended. 'escape' plays the break-free; 'throw'/'break' only leave the grabbed pose
 *  (the throw's hit, a hazard's hit or Loial decide what happens next) */
leaveGrabbed(how) {
  if (how === 'escape') { this.shoveFx = false; this.vx = 0; return this.setState('escape', 'escape'); }
  if (this.state === 'grabbed') this.setState('idle', 'idle');
}
grabbed(dt, inp) {
  const c = this.grabbedBy; this.vx = 0;
  if (!c) return this.setState('idle', 'idle');   // safety: the hold ended without leaveGrabbed
  let n = 0;
  for (const a of GRABBED.mashKeys) if (inp.take(a)) n++;   // jump/special/balefire never act while held
  const d = `${inp.x || 0},${inp.y || 0}`;
  if (d !== this.mashDir && d !== '0,0') n++;                  // every new (non-neutral) direction adds 1
  this.mashDir = d;
  for (let i = 0; i < n && this.grabbedBy; i++) this.grabbedBy.mash();   // stops once mash() frees him
}
escape(dt) {
  const c = this.lastGrabber;
  if (!this.shoveFx && this.fi >= GRABBED.shoveFrame) {
    this.shoveFx = true; const dir = c ? Math.sign(c.x - this.x) || -this.facing : -this.facing;
    this.scene.fx.impact('medium', this.x + dir * 50, this.y - 150, dir); sfx.hit(false);
    say('riley_escape_01', this.scene.caption, false);   // silent until T8 adds the line (audio.js:327-328)
  }
  if (this.done) { this.setState('idle', 'idle'); if (c && c.alive) this.face(Math.sign(c.x - this.x)); this.lastGrabber = null; }
}
```
- **Mash forwarding only.** Each counted press calls `mash()` once, in the same frame, during `R.update` (`src/stage1.js:669`),
  i.e. **before** the cutthroat's `holding(dt)` runs its decay for that frame (`:671-672`). Riley does not buffer,
  batch or rate-limit presses, so the timing math in §1 (T4) is exactly what the player gets.
- The shove beat is **feedback only** (impact FX + sfx). It deals no damage: T4's `mash()` has already put the
  cutthroat in `shoved` with `vx = holdSide * shoveKb`, and a `takeHit` here would knock him out of his ×1.3 window.
- Riley never clears `grabbedBy` himself (T4 §3.4).

## 5. Edge cases
- **Mash windows are aligned to the hold start**, not to the first press. Six presses 0.09 s apart starting at hold
  time 0.1 s straddle the 0.5 s tick and leave the count at 5. Riley-side code can't and doesn't change this; tests
  start mashing on the first frame of the hold (§6.1).
- **Presses buffered just before the grab** (within `Input.take`'s 0.18 s window, `src/input.js:51`) count as mash.
  Accepted (at most one per key).
- **Several counted presses in one frame:** the loop stops as soon as `grabbedBy` is cleared; extras are dropped.
- **Held direction at grab time** does not count (seeded into `mashDir`); releasing and pressing it again does.
- **Hit-stop / slowmo / pause:** `R.update` is not called during hit-stop (`src/stage1.js:661-666`) or while paused
  (`scene.pause()`, `setPauseReason` `:250-259`; the harness returns early on `s.paused`,
  `tests/helpers/stage1-simulation.mjs:135`), so Riley's `st`, `fi` and `mashDir` freeze with the cutthroat's `st`,
  `mashT`, `mashN` and `chips`. `setPauseReason` calls `inp.clear()` (`:254`) on pause and on resume, so a press
  made just before pausing is dropped, not replayed as mash. Slowmo scales both sides' `dt` equally (`:667-668`).
- **Victory, Loial, hazard, death, respawn while held:** all end via T4 (`releaseHold('break')` → `leaveGrabbed`, or
  the break check). `leaveGrabbed('break')` only resets a Riley still in `grabbed`; `down`/`getup` are left alone.
- **Throw:** T4 calls `releaseHold('throw')` before `hitTarget`, so `grabbedBy` is `null` and the throw hit passes the
  filter; `leaveGrabbed('throw')` sets `idle` first, then `takeHit` sets `down`.
- **Missing anims** (should not happen in Stage 3): `Fighter.play` warns and keeps the current frame
  (`src/fighter.js:15`); the state machine still works. Never substitute other Riley frames.
- **Grabber destroyed mid-escape:** `lastGrabber` may be `gone`; `escape` only reads `x`/`alive`, then drops it.

Helpers (local to the file; **frame counts, not seconds**, so no float loop bound like `0.15 * 60` can add a frame):
- `steps(h, n)`: `for (let i = 0; i < n; i++) h.step()`.

- `hold(h)`: `c = placeC(s, -220)`, `c.startLunge()`, `runUntil(h, 72, () => c.state === 'holding') > 0`, assert

  `for (let i = 0; i < n; i++) { if (i) steps(h, gap - 1); press(h, 'attack'); }`. The k-th press (1-based) lands on
  hold frame `1 + (k-1)*gap`. Returns after the last press's step. Decay ticks fall on hold frame 30 (±1 float), 60, …
