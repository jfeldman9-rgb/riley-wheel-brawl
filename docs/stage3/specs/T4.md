### 3.2 `export class Cutthroat extends Whitecloak`
- `constructor(scene, x, y)`: `super(scene, 'cutthroat', x, y)` (Whitecloak bumps `scene.koCount`,
  `src/whitecloaks.js:35`); `grabCool = rand(...firstGrab)`; `mashN = mashT = chips = 0; lungeDir = -1; stalking = false`.
- `get canBeHit()` → `super.canBeHit && this.state !== 'dropin'`.
- `play(name, ts, restart)`: `name === 'walk' && this.stalking` → `'stalk'`; then `super.play(...)`.
- `covers(R)` (pure): `RILEY_ATTACKS.includes(R.state) && R.atk && R.atk.active.includes(R.fi) &&
  Math.sign(this.x - R.x) === (R.atk.x1 > 0 ? R.facing : -R.facing)` (`back` reaches behind, `x1 < 0`, `src/riley.js:12`).
- `catchResult(R)` (pure) → `'grab' | 'counter' | null`:
  - `null` if `|R.y - y| >= catchDy`, `|R.x - x| >= catchDx`, `!R.alive`, `R.grabbedBy`, `s.victoryPending || s.ended`.
  - `'counter'` if `covers(R)`.
  - `'grab'` if `R.z <= 0 && R.vulnerable && (GRAB_OK ∪ RILEY_ATTACKS).includes(R.state)` (attacking but not covering
    = attacking away). Else `null`: `down getup air squat hold grab knee throw cast balefire` are never grabbed.
- `think(dt)`: return if `entering`. `R = this.target`, `adx`, `ady`.
  - If `cool <= 0 && grabCool <= 0 && R.alive && !R.grabbedBy && R.state !== 'down' && lungeRange[0] <= adx <=
    lungeRange[1] && ady < lungeLane && !s.grabBusy(this) && s.attackTokens() < s.maxTokens` → `return this.startLunge()`.
  - `stalking = cool > 0 || s.attackTokens() >= s.maxTokens`; `super.think(dt)` (`Enemy.think`, `src/enemies.js:44-60`:
    flank slot + slash via `T.atk`).
- `startLunge()`: face Riley, `lungeDir = facing`, `setState('lunge', 'lunge')`, `grabCool = rand(...grabCool)`,
  `cool = rand(...T.cool)`, `s.kit?.telegraph(this)`, `sfx.hiss?.()` (T8 adds `hiss`).
- `update(dt)`: `if (grabCool > 0) grabCool -= dt`. Own states do `this.st += dt` and `return` (Zealot pattern,
  `src/whitecloaks.js:71-78`); anything else → `super.update(dt)`.
  - `'dropin'`: while `st < dropMark`: `z = 0`, `sprite.setAlpha(0)`. First frame with `st >= dropMark && !falling`:
    `falling = true`, `z = dropZ`, `vz = 0`, `sprite.setAlpha(1)`. `Fighter.physics` (`src/fighter.js:28`) owns the fall.
  - `'lunge'`: `st < coil` → nothing. While `st < coil + lungeMax`: `x += lungeDir * lungeSpeed * dt`, then
    `r = catchResult(R)`: `'grab'` → `startHold(R)`; `'counter'` → `if (!R.hitIds.has(this.id)) s.hitTarget(R, this,
    R.atk)` (booked in `takeHit`). Wall (`x <= bounds.l + 50 || x >= bounds.r - 50`) or `st >= coil + lungeMax` → stop
    moving; stay in `lunge` until `done` (frame-4 stumble), then `setState('approach', 'walk')`.
  - `'holding'` → `holding(dt)` (§3.3). `'grabthrow'`: when `done` → `approach`, `cool = rand(...T.cool)`.
  - `'shoved'`: when `done && cur !== 'cutthroat_dazed'` → `play('dazed')`. `st >= shoved` → `approach`,
    `cool = rand(0.3, 0.6)`.
- `onLand(v)`: if `dropin`: `setState('approach', 'walk')`, `sprite.anims.resume()`, `cool = rand(0.4, 0.8)`,
  `s.fx.thump(x, y, false)`, `sfx.thud()`, `bump(s, 'dropins')`. Else `super.onLand(v)`.
- `sync()`: `super.sync()`; while `dropin && st < dropMark`: `g = st / dropMark`,
  `shadow.setScale(def.shadowW/64*g, def.shadowW*0.22/64*g).setAlpha(0.9*g)` (growing marker, existing `shadow` texture).
- `dropIn()`: `setState('dropin', 'lunge')`, `sprite.anims.setCurrentFrame(sprite.anims.currentAnim.frames[2])`,
  `sprite.anims.pause()` (painted airborne frame, as `Enemy.throwFrom`, `src/enemies.js:110`), `falling = false`, `z = 0`,
  `sprite.setAlpha(0)`, `s.kit?.dropMarker?.(this)` (optional T7 hook).
- `takeHit(h, from)`: `if (!this.canBeHit) return false`. `holding` → `releaseHold('break')` (Loial, fireball,
  hazard). `lunge && from === s.riley` → `bump(s, 'counters')`, `s.kit?.hint?.('counter', 'COUNTER!')`,
  `h = { ...h, down: true }`. `shoved` → `h = { ...h, dmg: h.dmg * shovedDmg }`. `return super.takeHit(h, from)`.
- `die(dir, h)`: `if (state === 'holding') releaseHold('break')`; `super.die(dir, h)`. Covers the `bossDown` sweep
  (`src/stage1.js:344`).

### 3.3 Hold
- `startHold(R)`: `side = Math.sign(x - R.x) || -R.facing`; if `R.x + side*holdDx` ∉ `[bounds.l+40, bounds.r-40]`, flip
  `side`. `R.face(-side)` (holder behind), `R.grabbedBy = this`, `R.vx = 0`, `R.enterGrabbed?.(this)` (T5).
  `setState('holding', 'hold')`, `holdSide = side`, `mashN = mashT = chips = 0`, `bump(s, 'grabs')`,
  `say('cutthroat_grab_01', s.caption, false)` (silent until T8), `s.kit?.hint?.('grabbed', 'GRABBED! MASH TO BREAK FREE')`.
- `holding(dt)`, in order:
  1. **Break check.** `!R.alive || R.grabbedBy !== this || ['hurt','down','getup','dead'].includes(R.state) ||
     s.victoryPending || s.ended` → `releaseHold('break')`, `setState('approach', 'walk')`, `cool = rand(0.6, 1.0)`,
     return. A hazard hit, death or respawn breaks the hold without T5.
  2. **Pin.** `x = R.x + holdSide*holdDx`, `y = Math.max(LANE_TOP, R.y - 1)` (drawn behind), `z = 0`, `vx = 0`,
     `face(-holdSide)`.
  3. **Decay (unconditional).** `mashT += dt; while (mashT >= mashDecay) { mashT -= mashDecay; mashN = Math.max(0,
     mashN - 1); }`. Presses never reset `mashT`, so the count drops by 1 every 0.5 s of hold time even while mashing.
  4. **Chip (exactly 3).** `if (chips < chipMax && st >= (chips + 1) * chipEvery && st < holdMax) { chips++; if (R.hp >
     1) R.hp = Math.max(1, R.hp - chipDmg); sfx.hit(false); }` → chips at 0.6, 1.2, 1.8 s; none at or after `holdMax`.
     Counting (not a `chipT` accumulator) makes the count float-proof. Never knocks down or kills (same floor as fire
     patches, `src/stage1.js:633`).
  5. **Timeout.** `st >= holdMax` → `releaseHold('throw')`, `setState('grabthrow', 'grabthrow')`,
     `s.hitTarget(this, R, CUTTHROAT.throwHit)` (8 dmg, knockdown; `grabbedBy` is already `null`, so T5's filter passes).
- `mash()` (public; T5 calls it per counted press): `if (state !== 'holding') return false; mashN++;` (no `mashT`
  reset). If `mashN >= mashNeed`: `releaseHold('escape')`, `setState('shoved', 'shoved')`, `vx = holdSide * shoveKb`,
  `s.kit?.hint?.('shoved', 'BREAK FREE! HIT HIM NOW')`, return `true`. Else `false`.
  Net effect: escape needs 6 presses inside one 0.5 s decay window, or sustained mashing of about 5 presses/s
  (0.2 s rhythm escapes at ≈1.8 s); 1 press per 0.45 s never gets past 1.
- `releaseHold(how)`: `if (R.grabbedBy === this) { R.grabbedBy = null; R.leaveGrabbed?.(how); bump(s, how === 'escape' ?
  'escapes' : how === 'throw' ? 'throws' : 'breaks'); }`. The bump is inside the `if` (resolves T5 §8.7). Never calls
  `setState`.

### 3.4 Riley contract (T5 implements it; T4 only uses `?.`)

## 6. Edge cases
- **Riley at a wall:** `startHold` flips the side. **`R.y === 572`:** holder shares his y; T5's `sync` draws Riley in front.
- **Two lunges:** `grabBusy` blocks the second; `R.grabbedBy` in `catchResult` blocks a double hold.
- **Riley holding an enemy** (`grab`/`hold`/`knee`/`throw`): not grabbable. A cutthroat in `lunge`/`holding`/`dropin`
  is not `grabbable` (`src/enemies.js:25`).
- **Victory while holding:** `bossDown` (`:344`) → `die` → release. **Pause/hit-stop** skip `update` (`:661-666`,
  `scene.pause()`): hold, chip, decay and drop-in freeze. **KO/flee:** Whitecloak paths unchanged.
- **Archers** don't take tokens and fire through `kit.fireArrow` → `R.takeHit` (`src/stage2.js:127`), not
  `resolveAttack`; T5's `takeHit` filter blocks them.
- **No T5:** Riley is pinned by the holder's position only; a hit puts him in `hurt`/`down`, which breaks the hold.
- **Plain `stage1Simulation` into Stage 3** now spawns cutthroats on zone 0 and has no cutthroat meta
  (`stage1-simulation.mjs:24`); any Stage 3 sim past `at` 260 (T11, T12) must use `stage3-harness.mjs`.

## 9. Discrepancies with PLAN.md and open questions
1. **Harness.** PLAN says `stage1Simulation` with `stage: 3, s3: '1'`; there is no `s3` option (T1 reads the flag
   from `q`, `src/config.js:5`), and the helper can't play non-boot anims. §7.1's wrapper avoids editing it. T5/T6
   reuse it; T6 adds `'fade'` to `STAGE3_METAS`.
2. **Assets and loading** follow T2 §2 / T3 §3.3 (`assets/stage3/chars/`, `queueStage3`); T4 adds no loader code.
3. **T4/T5 split (approved).** The `resolveAttack` guard (PLAN T5) is T4 §4.5. Loial knocks the cutthroat off through
   `Cutthroat.takeHit`, so `loial.js` needs no change. Arrows are blocked only by T5's `Riley.takeHit` filter.
4. **Mash decay (Jason).** The count decays every 0.5 s regardless of presses (old spec's `mashT = 0` in `mash()`
   removed). So PLAN's "6 presses inside 2.4 s" means quick mashing: 6 within 0.5 s, or ≈5/s sustained. When T5 is
   rebased, its test 2 (6 presses 0.15 s apart → count 5, no escape) must be retimed; T12's bot must mash ≥ 5/s.
5. **Chip (Jason).** Exactly 3 chips of 2 (0.6/1.2/1.8 s), counted with `chipMax`, floored at hp 1, so death while
   held comes only from the throw or a hazard.
6. **Dependency on T3** (kit hooks, atlas loading, `Stage3Kit` in the harness); PLAN's graph shows only T2 → T4.
7. **Token rule.** "The grabber holds the only token" = `attackTokens()` returns `maxTokens` while anyone is `holding`.
8. **Unspecified values chosen:** slash `x1: 200`, kb 200; lunge range 140–300 px; catch box 80×22 px; first grab
   2.0–3.5 s; `holdDx` 46; `shoveKb` 260. Tune once, in T12.
9. **Grabs from the front.** PLAN also allows grabbing a non-attacking Riley who faces the cutthroat; kept, and Riley
   is always turned so the holder is behind him.
10. **New since the `afebe67` draft:** body-block also skips `dropin`; `releaseHold` bumps only on a real release
    (T5 §8.7); `ENEMY_CLASSES` is exported (test 12; T6 extends it); `arena()` disables waves for unit tests.
