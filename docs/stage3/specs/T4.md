### 3.2 `export class Cutthroat extends Whitecloak`
- `constructor(scene, x, y)`: `super(scene, 'cutthroat', x, y)`; `this.grabCool = rand(...CUTTHROAT.firstGrab)`;
  `this.mashN = 0; this.mashT = 0; this.chipT = 0; this.lungeDir = -1; this.stalking = false`.
- `get canBeHit()` → `super.canBeHit && this.state !== 'dropin'`.
- `play(name, ts, restart)`: if `name === 'walk' && this.stalking`, use `'stalk'`. Then `super.play(...)`.
- `covers(R)` (pure): `RILEY_ATTACKS.includes(R.state) && R.atk && R.atk.active.includes(R.fi) &&
  Math.sign(this.x - R.x) === (R.atk.x1 > 0 ? R.facing : -R.facing)`. The `back` attack reaches behind
  (`x1 < 0`, `src/riley.js:12`).
- `catchResult(R)` (pure, returns `'grab' | 'counter' | null`):
  - `null` if `Math.abs(R.y - this.y) >= catchDy`, `Math.abs(R.x - this.x) >= catchDx`, `!R.alive`, `R.grabbedBy`,
    or `this.scene.victoryPending || this.scene.ended`.
  - `'counter'` if `this.covers(R)`.
  - `'grab'` if `R.z <= 0 && R.vulnerable && (GRAB_OK.includes(R.state) || RILEY_ATTACKS.includes(R.state))`.
    (Attacking but not covering him counts as attacking away.) Otherwise `null`. So `down`, `getup`, `air`, `hold`,
    `grab`, `throw`, `cast`, `balefire` and `squat` are never grabbed.
- `think(dt)`: return if `entering`. `const R = this.target, s = this.scene, adx = |R.x - x|, ady = |R.y - y|`.
  - If `cool <= 0 && grabCool <= 0 && R.alive && !R.grabbedBy && R.state !== 'down' && adx >= lungeRange[0] &&
    adx <= lungeRange[1] && ady < lungeLane && !s.grabBusy(this) && s.attackTokens() < s.maxTokens`, then
    `return this.startLunge()`.
  - `this.stalking = this.cool > 0 || s.attackTokens() >= s.maxTokens`, then `super.think(dt)` (`Enemy.think`
    flank slot plus slash through `T.atk`).
- `startLunge()`: face Riley, `lungeDir = facing`, `setState('lunge', 'lunge')`, `grabCool = rand(...grabCool)`,
  `cool = rand(...T.cool)`, `s.kit?.telegraph(this)`, `sfx.hiss?.()` (T8 adds `hiss`).
- `update(dt)`: `if (this.grabCool > 0) this.grabCool -= dt`. Then switch, where each own state does
  `this.st += dt` and `return`s (the Zealot pattern, `src/whitecloaks.js:71-78`). Anything else goes to `super.update(dt)`.
  - `'dropin'`: if `st < dropMark`, keep `z = 0` and `sprite.setAlpha(0)`. On the first frame with `st >= dropMark`
    (`!this.falling`): `falling = true`, `z = dropZ`, `vz = 0`, `sprite.setAlpha(1)`. Physics owns the fall and
    `onLand` ends it.
  - `'lunge'`: if `st < coil`, do nothing (frame 0 is the 450 ms coil). Otherwise, while `st < coil + lungeMax`:
    `x += lungeDir * lungeSpeed * dt`, then `r = catchResult(R)`:
    - `'grab'` → `startHold(R)`.
    - `'counter'` → `if (!R.hitIds.has(this.id)) s.hitTarget(R, this, R.atk)`. `takeHit` (below) books the counter.
    - Wall (`x <= bounds.l + 50` or `x >= bounds.r - 50`) or `st >= coil + lungeMax` → stop moving and stay in
      `lunge` until `done` (the frame-4 miss-stumble). Then `setState('approach', 'walk')`.
  - `'holding'` → `holding(dt)` (§3.3). `'grabthrow'`: when `done`, go to `approach` with `cool = rand(...T.cool)`.
  - `'shoved'`: when the `shoved` anim is `done` and `cur !== 'cutthroat_dazed'`, `play('dazed')`. When
    `st >= shoved`, go to `approach` with `cool = rand(0.3, 0.6)`.
- `onLand(v)`: if `state === 'dropin'`: `sprite.anims.resume()`, `setState('approach', 'walk')`,
  `cool = rand(0.4, 0.8)`, `s.fx.thump(x, y, false)`, `sfx.thud()`, `bump(s, 'dropins')`. Otherwise `super.onLand(v)`.
- `sync()`: `super.sync()`. Then, while `state === 'dropin' && st < dropMark`, `g = st / dropMark` and
  `shadow.setScale(def.shadowW/64*g, def.shadowW*0.22/64*g).setAlpha(0.9*g)`. That is the growing ground marker. It
  uses the existing `shadow` texture (no new art).
- `dropIn()`: `setState('dropin', 'lunge')`, `sprite.anims.setCurrentFrame(sprite.anims.currentAnim.frames[2])`,
  `sprite.anims.pause()` (the painted airborne-reach frame, as in `Enemy.throwFrom`), `falling = false`, `z = 0`,
  `sprite.setAlpha(0)`, `s.kit?.dropMarker?.(this)` (optional T7 hook).
- `takeHit(h, from)`:
  - `if (!this.canBeHit) return false`.
  - If `state === 'holding'`: `releaseHold('break')`. This covers Loial, a fireball, or a hazard hitting him.
  - If `state === 'lunge' && from === s.riley`: `bump(s, 'counters')`, `s.kit?.hint?.('counter', 'COUNTER!')`,
    `h = { ...h, down: true }`.
  - If `state === 'shoved'`: `h = { ...h, dmg: h.dmg * CUTTHROAT.shovedDmg }`.
  - `return super.takeHit(h, from)`.
- `die(dir, h)`: `if (state === 'holding') releaseHold('break')`, then `super.die(dir, h)`. This also covers the
  `bossDown` sweep, `src/stage1.js:318`.

### 3.3 Hold
- `startHold(R)`:
  - `side = Math.sign(this.x - R.x) || -R.facing`. If `R.x + side*holdDx` is outside `[bounds.l+40, bounds.r-40]`,
    flip `side`.
  - `R.face(-side)`, so Riley faces away and the cutthroat is behind him. `R.grabbedBy = this`. `R.vx = 0`.
  - `R.enterGrabbed?.(this)` (T5).
  - `setState('holding', 'hold')`, `holdSide = side`, `mashN = mashT = chipT = 0`, `bump(s, 'grabs')`.
  - `say('cutthroat_grab_01', s.caption, false)` (silent until T8), `s.kit?.hint?.('grabbed', 'GRABBED! MASH TO BREAK FREE')`.
- `holding(dt)`, in this order:
  1. **Break check.** If `!R.alive || R.grabbedBy !== this || ['hurt','down','getup','dead'].includes(R.state) ||
     s.victoryPending || s.ended`, call `releaseHold('break')`, `setState('approach', 'walk')`,
     `cool = rand(0.6, 1.0)` and return. This is how a hazard hit or a respawn breaks the hold without T5.
  2. **Pin.** `x = R.x + holdSide*holdDx`, `y = Math.max(LANE_TOP, R.y - 1)` (drawn behind), `z = 0`,
     `face(-holdSide)`.
  3. **Decay.** `mashT += dt`. While `mashT >= mashDecay`: `mashT -= mashDecay` and `mashN = Math.max(0, mashN - 1)`.
  4. **Chip.** `chipT += dt`. If `chipT >= chipEvery && st < holdMax`: `chipT -= chipEvery`,
     `R.hp = Math.max(1, R.hp - chipDmg)`, `sfx.hit(false)`. Chip never knocks down or kills (same floor as the
     fire patches, `src/stage1.js:618`).
  5. **Timeout.** If `st >= holdMax`: `releaseHold('throw')`, `setState('grabthrow', 'grabthrow')`,
     `s.hitTarget(this, R, CUTTHROAT.throwHit)`.
- `mash()` (public, called by T5 for every counted press): if `state !== 'holding'` return `false`. Otherwise
  `mashN++`, `mashT = 0`. If `mashN >= mashNeed`: `releaseHold('escape')`, `setState('shoved', 'shoved')`,
  `vx = holdSide * shoveKb`, `s.kit?.hint?.('shoved', 'BREAK FREE! HIT HIM NOW')`, return `true`. Otherwise `false`.
- `releaseHold(how)`: `if (R.grabbedBy === this) { R.grabbedBy = null; R.leaveGrabbed?.(how); }`, then
  `bump(s, how === 'escape' ? 'escapes' : how === 'throw' ? 'throws' : 'breaks')`. It never calls `setState`.

### 3.4 Riley contract (T5 implements it; T4 only uses `?.`)
`R.grabbedBy` (owned and cleared by the cutthroat), `R.enterGrabbed(c)`, `R.leaveGrabbed(how)` where `how` is
`'escape' | 'throw' | 'break'`, and T5 calls `R.grabbedBy.mash()` per press. T5 must not clear `grabbedBy` itself
except through `c.releaseHold`.

## 6. Edge cases
- **Riley at a wall:** `startHold` flips the side so the cutthroat is never clamped onto Riley.
- **`LANE_TOP`:** at `R.y === 572` the holder's y equals Riley's (same depth). T5 owns the sprite depth.
- **Two lunges:** `grabBusy` blocks the second at start. If two cutthroats ever overlap, the `R.grabbedBy` check in
  `catchResult` blocks a double hold.
- **Riley holding an enemy** (`grab`/`hold`/`knee`/`throw`): not in `GRAB_OK`, so it is never grabbed.
- **Victory while holding:** `bossDown` → `die` → release. In `waves`, the break check also releases.
- **Pause and hit-stop:** `update` is not called, so the hold, chip, mash and drop-in timers freeze.
- **Fleeing or KO:** the Whitecloak paths are unchanged. `fleeGetup`/`flee` are reachable only from `down`, never
  from `holding`.
- **`T` spawn in a non-cutthroat entry** falls back to `R`. A `T` spawn ignores `entering` (it is placed inside the
  bounds).
- **No T5:** an idle Riley is pinned by position only. A hit puts him in `hurt`/`down`, which breaks the hold.

   cannot play non-boot anims. The new wrapper helper (§7.1) avoids editing it. T5 and T6 should reuse it (T6 adds

   filter.
