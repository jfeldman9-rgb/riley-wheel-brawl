### 3.1 Header, types, constants
```js

// it kneels and melts back into shadow. Copies use the same painted frames (no tint, no recolour) but are unlit.
import { Enemy, TYPES } from './enemies.js';
import { clamp, rand, q, LANE_TOP, LANE_BOT } from './config.js';
import { sfx } from './audio.js';
const D = (key, scale, anchorX, hp, shadowW) => ({ key, prefix: key + '_', native: -1, scale, anchorX, hp, team: 1, shadowW });
Object.assign(TYPES, {
  fade: { def: D('fade', 0.56, 0.5, 440, 180), name: 'THE MYRDDRAAL', speed: 110, pref: 210, cool: [0.9, 1.5], score: 7000, boss: true,
    atk: { anim: 'slash', active: [2, 4], x0: 20, x1: 260, z0: 0, z1: 240, dmg: 12, kind: 'medium', kb: 300, sfx: 'blade' } },
});
TYPES.fadecopy = { ...TYPES.fade, def: { ...TYPES.fade.def, hp: 1 }, boss: false, score: 0 };   // same key/prefix → same frames
const deep = o => { for (const v of Object.values(o)) if (v && typeof v === 'object') deep(v); return Object.freeze(o); };
export const FADE = deep({
  blink: { every: [4, 6], everyP2: [6, 8], poolWarn: 0.6, counterFrames: [2, 3], behind: 110, edge: 70 },
  fear: { radius: 300, fill: 1.4, shaken: 0.7, dispel: 4, dispelRange: 400, vig: [0.35, 0.75], torchDim: 0.7,
    rampIn: 0.5, rampOut: 0.3, pulse: 0.03, auraFrame: 3, hurtMs: 340 },   // hurtMs = riley_hurt holds 80+140+120 (assets/chars/riley.anims.json:173-177)
  split: { copies: 2, every: [8, 10], wrongHitPunish: 0.3, spread: [280, 460], order: [0.8, 1.6, 2.4], relunge: [2.4, 3.2] },
  counter: { stagger: 1.4, mul: 1.5 }, reduction: 0.6, wake: 0.8, melt: 1.2,

const bump = (s, k) => { const st = s.kit?.stats; if (st) st[k] = (st[k] || 0) + 1; };
```

### 3.3 `export class Myrddraal extends Enemy` (not Whitecloak: no KO/flee)
- `constructor(scene, x, y)`: `super(scene, 'fade', x, y)`; `this.T = { ...TYPES.fade }` (per instance, as Byar
  `src/whitecloaks.js:189`); `isCopy = false; phase = 1; cool = 1.6; introDone = false; wake = 0;`
  `nextBlink = rand(...blink.every); pool = null; copies = []; auraOn = false; auraK = 0; fear = 0; dispelT = 0;`
  `pendingFear = pendingSplit = false; resplitT = 0; forceLungeT = 0; lungeAt = 99; melting = false; meltT = 0;`
  `lastActive = -1; t = 0`. **No `setLighting` call** (§3.7).
- `get grabbable()` → `false`. `poise()` → `9`.
- `get canBeHit()` → `alive && !entering && !['dead','down','getup','defeated','sunk'].includes(state)`.
- `update(dt)`, in order:
  1. `this.t += dt`; `getup` done → `approach`, `cool = 0.2`, `wake = FADE.wake`, return. `if (wake > 0) wake -= dt`.
  2. Phase (alive only), Byar's formula (`src/whitecloaks.js:197`) `f > 0.66 ? 1 : f > 0.33 ? 2 : 3`. On change:
     `scene.onBossPhase(this, ph)`; ph 2 → `pendingFear = true`; ph 3 → `pendingSplit = true`; `cool = 0` if in
     `approach`/`wait`.
  3. Timers: `nextBlink -= dt; forceLungeT -= dt; lungeAt -= dt; if (resplitT > 0 && (resplitT -= dt) <= 0 && phase === 3) pendingSplit = true`.
  4. `tickFear(dt)` then `tickLook(dt)` (§3.5). Both run in every state, including `defeated`.
  5. Own states (`st += dt; cool -= dt; shudder` like Byar `:206`), then `switch`:
     - `intro` (anim `intro`): first frame `sfx.shadowWhoosh?.()`; done → `approach`, `introDone = true`, `cool = 1.0`.
     - `attack`: Byar's two-hit `attacking` (`src/whitecloaks.js:244-251`); last active frame uses `{...a, ...FADE.thrust}`.
     - `lunge`: `lungeTick(this, dt, FADE.lunge.hit)` (§3.4).
     - `blinkout` (anim): done → `state = 'sunk'`, `st = 0`, `pool = { ...poolSpot(R, s.bounds), t: 0 }`,
       `pool.fx = s.kit?.shadowPool?.(pool)`, `sfx.shadowWhoosh?.()`.
     - `sunk`: `pool.t += dt`; at `st ≥ poolWarn`: `x = pool.x; y = pool.y; face(sign(R.x - x))`,
       `s.kit?.shadowPoolEnd?.(pool)`, `pool = null`, `setState('blinkin', 'blinkin')`.
     - `blinkin`: done → `startAttack()` (rises and slashes; bypasses the token check).
     - `fear` (anim): at `fi ≥ auraFrame` and `!auraOn` → `auraOn = true`, `bump(s,'fears')`,
       `s.kit?.hint?.('fear', 'FEAR AURA! FIRE OR LIGHTNING DRIVES IT BACK')`. Done → `approach`, `cool = rand(0.4, 0.8)`.
     - `split` (anim): done → `makeCopies()`, `approach`, `cool = 0.6`.
     - `stagger` (anim, then holds its last frame): `st ≥ counter.stagger` → `approach`, `cool = rand(0.3, 0.6)`.
     - `defeated`: anim done and `!melting` → `melting = true`, `s.kit?.shadowBurst?.(x, y)`. While melting:
       `meltT += dt`, `a = max(0, 1 - meltT / FADE.melt)`, sprite + shadow alpha `a`; `a === 0` → `gone = true`
       (the scene filter destroys it, `src/stage1.js:693`).
     - otherwise `super.update(dt)` (`src/enemies.js:26-38`).
- `think(dt)`: return if `entering`. `!introDone` → `setState('intro','intro')`, return (the line is `startBoss`'s,
  `src/stage1.js:316`). If `forceLungeT > 0 && R.alive` → `startLunge()`. If `cool ≤ 0 && R.alive && R.state !==
  'down'`: `pendingFear` → `startFear()`; `pendingSplit` → `startSplit()`; `nextBlink ≤ 0 && !copies.length` →
  `startBlink()`; phase 3 `lungeAt ≤ 0` → `startLunge()`; `adx ∈ lunge.range && ady < lane && s.attackTokens() <
  s.maxTokens && Math.random() < chance` → `startLunge()`. Else `super.think(dt)` (`src/enemies.js:44-60`, slash via
  `startAttack`).
- `startAttack()`: Byar's (`src/whitecloaks.js:242`). `startLunge()`: face Riley, `setState('lunge','lunge')`,
  `forceLungeT = 0`, `lungeAt = rand(...split.relunge)`, `hitIds.clear()`, `s.kit?.glint?.(x - facing*60, y - 220,
  0xffffff)`, `sfx.glint()`.
- `startBlink()`: `setState('blinkout','blinkout')`, `nextBlink = rand(...(phase === 1 ? every : everyP2))`, `bump(s,'blinks')`.
- `startFear()`: `pendingFear = false`, `setState('fear','fear')`. `startSplit()`: `pendingSplit = false`, `setState('split','split')`.
- `makeCopies()`: `side = sign(x - R.x) || 1`; spots `[R.x - side*spread[0], R.x + side*spread[1]]`, each clamped to
  `[bounds.l + 80, bounds.r - 80]`, `y = clamp(R.y ± 30, LANE_TOP, LANE_BOT)`. `new FadeCopy(s, x, y, this)` ×2, pushed
  to `s.enemies` and `this.copies`. Shuffle `split.order` with `Math.random` and assign `lungeAt` to [real, c1, c2].
  `bump(s,'splits')`, `s.kit?.hint?.('copies', 'ONLY THE REAL ONE CASTS A SHADOW AND CATCHES THE TORCHLIGHT')`.
- `inParry()`: `phase === 3 && ((state === 'lunge' && fi <= 2) || (state === 'attack' && fi <= 4))`.
- `takeHit(h, from)` (any source counts; fireball, Balefire and lightning arrive with a plain `src`,
  `src/stage1.js:410, 450`, `src/powers.js:144`):
  1. `if (!canBeHit) return false`.
  2. `blinkin` with `fi ∈ counterFrames`, or `inParry()` → `counterHit(h, from)`: `hp -= dmg * counter.mul`,
     `shudder = 0.12`, `setState('stagger','stagger')`, `vx = 0`, `bump(s, inParry ? 'parries' : 'counters')`,

     `hp ≤ 0` → `die`. Return `true`.
  3. `stagger` → `hp -= dmg * counter.mul` (no state change), `die` at 0, return `true`.
  4. `['blinkout','blinkin','fear','split','intro'].includes(state) || wake > 0` → Byar's ×0.6 branch

  5. `return super.takeHit(h, from)` (`src/enemies.js:66-80`; boss → no knockdown on `h.down`, poise 9).
- `die(dir, h)` (never `knockdown`): `heldBy = null; alive = false; hitsTaken = 0; vx = dir * 60;`

### 3.4 Lunge (shared by real and copy): `function lungeTick(e, dt, hit)`
Frame 0 (380 ms) is the telegraph: no motion. Frames 1–2: `e.x += e.facing * FADE.lunge.speed * dt` and
`e.scene.resolveAttack(e, hit)`. Wall (`x ≤ b.l + 60 || x ≥ b.r - 60`) stops motion. `e.done` → `approach`,
`e.cool = rand(...e.T.cool)`.

### 3.5 Fear (methods on Myrddraal)
- `get auraActive()` → `auraOn && dispelT <= 0 && alive`.
- `tickFear(dt)`: if `auraOn` and `lightNear(s, x, fear.dispelRange)`: if `dispelT <= 0` → `bump(s,'dispels')`,
  `s.kit?.hint?.('dispel', 'LIGHT DRIVES THE SHADOW BACK!')`; `dispelT = fear.dispel`. Else `dispelT = max(0, dispelT - dt)`.
  Meter: `inside = auraActive && R.alive && hypot(R.x - x, R.y - y) <= radius`; `fear = clamp(fear ± dt / fill, 0, 1)`.
  When `fear >= 1` and `R.vulnerable` (`src/riley.js:27`) `&& R.z <= 0 && !R.grabbedBy &&
  !['hurt','down','getup','balefire','grabbed','escape'].includes(R.state)`:
  `R.setState('hurt','hurt', fear.hurtMs / (fear.shaken * 1000))`, `R.vx = 0`, `fear = 0`, `bump(s,'shaken')`.
  No damage. (`grabbedBy`/`grabbed`/`escape` are T4/T5 names; without them the checks are simply false.)
- `tickLook(dt)`: `auraK` moves toward `auraActive ? 1 : 0` at `1/rampIn` up, `1/rampOut` down, clamped to `[0, 1]`
  (so it lands on exactly 0). Then
  `if (s.vignette) s.vignette.strength = vig[0] + (vig[1]-vig[0]) * auraK + (calmMotion() ? 0 : pulse * auraK * Math.sin(t * 4))`.
  For each `L` of `s.fires` (T3's torches): `L.baseR ??= L.radius; L.radius = L.baseR * (1 - (1 - torchDim) * auraK)`.
  Adds no lights. `s.vignette` is `null` with `?vig=0` or after `dropVignette()` (`src/stage1.js:161, 231`): skip
  silently. With `auraK === 0` the strength is exactly `0.35` and every radius exactly `baseR`.

### 3.7 Lighting contract (locked)
| | Real Myrddraal | `FadeCopy` |
|---|---|---|
| Sprite lighting | **lit**: `Fighter` builds every sprite with `.setLighting(true)` (`src/fighter.js:10`); `myrddraal.js` never calls `setLighting` on it, in any state including `defeated`/melt | **unlit**: `this.sprite.setLighting(false)` once, right after `super(...)`; never re-enabled |
| Responds to | ambient (T3 `timeOfDay`), torches in `s.fires` (and their fear dimming), hero light, fireball/power lights, normal maps `fade-*_n` | nothing: painted frames at full value |
| Ground shadow | yes (`Fighter.sync`) | hidden (`setVisible(false)` + alpha 0) |
| Frames / tint | `fade_*`, no tint except `flashArmor` on ×0.6 hits | identical `fade_*` frames; never tinted |

- **How:** Phaser 4's per-object `setLighting(bool)` is this codebase's one lit/unlit switch: lit objects call
  `setLighting(true)` (`src/fighter.js:10`, `src/stage1.js:198, 205, 485`), `setBackdropLit` flips plates with
  `o.setLighting(on)` (`:230`), and additive FX images (fireball `core`/`glow` `:393-394`, pickups `:503-504`) are
  unlit by never calling it. No `setPipeline`, no custom flag, no shader.
- Copies are never pushed to `s.backdropLit`, so `?lit=0` / the governor (`setBackdropLit`) can't relight them; the
  fighters stay lit there, so the tell survives. Digit1 lights-off (`toggleLights`, `:232`) sets a white ambient so the
  real one also looks flat: debug-only, accepted.
- Unlit copies render brighter and flatter than the torch-shaded real one at night: that **is** the tell, alongside
  the shadow, the lunge glint and T7's wisps.

## 5. Edge cases
- **Riley at a wall:** `poolSpot` flips to his front, never outside `bounds ± 70`.
- **Blink during a lunge/copies:** blinks only start from `think` and never while copies live.
- **Tokens (T4):** `attackTokens` counts any `lunge` (T4 §4.4), so a lunging Fade or copy holds a token. `forceLungeT`
  and `blinkin → startAttack` bypass tokens (bounded: one boss); copies obey them. T4's `grabBusy` also sees the Fade's
  `lunge`, harmless (no cutthroats in the boss zone).
- **Riley dead / respawning / game over:** `fear` decays (not `R.alive`); shaken needs `R.vulnerable`.
- **Riley grabbed (T5):** cannot happen in the boss arena; if it did, shaken is skipped and the Fade's `team: 1`
  hits are filtered by T5's `takeHit`.
- **Pause / hitstop:** `update` is not called (`src/stage1.js:661-666`, `scene.pause()`); every timer is `dt`-driven.
- **Victory mid-split / mid-blink / mid-fear:** `die` → `clearAbilities`; `tickLook` keeps ramping `auraK` to 0 during
  `defeated` (≥ 1.9 s of anim + 1.2 s melt ≫ 0.3 s), so the vignette ends at exactly 0.35 and every torch at `baseR`.
  `bossDown`'s sweep (`:344`) finds no live copy (already vanished); `STAGE3.bossDown` calls `kit.clearHazards()`.
- **Restart:** Phaser shutdown destroys sprites, lights and timers; `create()` makes a **new** vignette at 0.35
  (`:161`) and a new kit. No module-level state and no `delayedCall` in this file, so nothing from the old fight can
  write to the new vignette or `s.fires`.
- **Light budget (§2.5):** the Fade adds no lights; dimming changes radii only; copies, pools and wisps are unlit.
- **Boss bar:** the HUD fades on `state === 'defeated'` (`src/hud.js:244`), so the melt stays in `defeated` with
  `melting = true` instead of a separate `melt` state.
- **`?skip=boss`:** `STAGE3.skipBoss` (`:204`) → camX 3500; walking right past `at` 4140 calls `startBoss`.
