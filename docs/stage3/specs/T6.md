  aura that deepens the vignette and dims torches (cleared by fire/light powers), shadow copies with a parry on the
  real one, and a kid-safe melt-away defeat. Reachable only with `?stage=3&s3=1`.

  `resolveStage` with `s3`.

- **Needs T3:** `Stage3Kit` (inherits `glint`, `hint`, `stats`, `clearHazards` from `Stage2Kit`) and `queueStage3`

  `tests/helpers/stage3-harness.mjs` (`stage3Simulation`, `STAGE3_METAS`).

## 3. `src/myrddraal.js`

### 3.1 Header, types, constants
```js
// Stage 3 boss: the Myrddraal (a Fade). Shadow blink, fear aura, shadow copies. Kid-safe: never killed on screen;
// it kneels and melts back into shadow. Copies use the same painted frames: no tint, no recolour.
import { Enemy, TYPES } from './enemies.js';
import { clamp, rand, q, LANE_TOP, LANE_BOT } from './config.js';
import { sfx, say } from './audio.js';
const D = (key, scale, anchorX, hp, shadowW) => ({ key, prefix: key + '_', native: -1, scale, anchorX, hp, team: 1, shadowW });
Object.assign(TYPES, {
  fade: { def: D('fade', 0.56, 0.5, 440, 180), name: 'THE MYRDDRAAL', speed: 110, pref: 210, cool: [0.9, 1.5], score: 7000, boss: true,
    atk: { anim: 'slash', active: [2, 4], x0: 20, x1: 260, z0: 0, z1: 240, dmg: 12, kind: 'medium', kb: 300, sfx: 'blade' } },
});
TYPES.fadecopy = { ...TYPES.fade, def: { ...TYPES.fade.def, hp: 1 }, boss: false, score: 0 };   // same key/prefix → same frames
const deep = o => { for (const v of Object.values(o)) if (v && typeof v === 'object') deep(v); return Object.freeze(o); };
export const FADE = deep({
  blink: { every: [4, 6], everyP2: [6, 8], poolWarn: 0.6, counterFrames: [2, 3], behind: 110, edge: 70 },
  fear: { radius: 300, fill: 1.4, shaken: 0.7, dispel: 4, dispelRange: 400, vig: [0.35, 0.75], torchDim: 0.7,
    rampIn: 0.5, rampOut: 0.3, pulse: 0.03, auraFrame: 3, hurtMs: 340 },   // hurtMs = sum of riley_hurt holds [80,140,120]
  split: { copies: 2, every: [8, 10], wrongHitPunish: 0.3, spread: [280, 460], order: [0.8, 1.6, 2.4], relunge: [2.4, 3.2] },
  counter: { stagger: 1.4, mul: 1.5 }, reduction: 0.6, wake: 0.8, melt: 1.2,
  lunge: { speed: 760, range: [220, 420], lane: 30, chance: 0.5,
    hit: { x0: -10, x1: 170, z0: 0, z1: 240, dmg: 12, kind: 'heavy', kb: 400, launch: 320, down: true },
    copyHit: { x0: -10, x1: 170, z0: 0, z1: 240, dmg: 8, kind: 'medium', kb: 220 } },
  thrust: { dmg: 12, kind: 'heavy', down: true, kb: 380 },
});
export const calmMotion = () => q.get('flash') === '0' || !!globalThis.matchMedia?.('(prefers-reduced-motion: reduce)')?.matches;
const bump = (s, k) => { const st = s.kit?.stats; if (st) st[k] = (st[k] || 0) + 1; };
// blinks, counters, fears, dispels, shaken, splits, copiesPopped, parries
```

### 3.2 Pure helpers (exported for tests)
- `poolSpot(R, b)`: `x = R.x - R.facing * FADE.blink.behind`; if `x < b.l + edge || x > b.r - edge`, use
  `R.x + R.facing * behind` instead; then clamp to `[b.l + edge, b.r - edge]`. `y = clamp(R.y, LANE_TOP + 6, LANE_BOT - 6)`.
- `lightNear(s, x, range)` → `'fireball' | 'lightning' | 'fireshield' | 'balefire' | null`, first match in that order:
  `s.fireballs.some(f => |f.x - x| ≤ range)`; `s.powers?.bolts.some(b => b.L && |b.L.x - x| ≤ range)`;
  `s.powers?.active('fireshield') && |s.riley.x - x| ≤ range`; `s.beam && !s.beam.fade` and
  `u = (x - s.beam.x0) * s.beam.dir` with `-range ≤ u ≤ s.beam.len + range`. Polling only: `powers.js` is not edited.

### 3.3 `export class Myrddraal extends Enemy` (not Whitecloak: no KO/flee)
- `constructor(scene, x, y)`: `super(scene, 'fade', x, y)`; `this.T = { ...TYPES.fade }` (per-instance, as Byar);
  `isCopy = false; phase = 1; cool = 1.6; introDone = false; wake = 0; nextBlink = rand(...blink.every);`
  `pool = null; copies = []; auraOn = false; auraK = 0; fear = 0; dispelT = 0; pendingFear = pendingSplit = false;`
  `resplitT = 0; forceLungeT = 0; lungeAt = 99; melting = false; meltT = 0; lastActive = -1; t = 0`.
- `get grabbable()` → `false`. `poise()` → `9`.
- `get canBeHit()` → `alive && !entering && !['dead','down','getup','defeated','sunk'].includes(state)`.
- `update(dt)`, in order:
  1. `this.t += dt`; `getup` done → `approach`, `cool = 0.2`, `wake = FADE.wake`, return. `if (wake > 0) wake -= dt`.
  2. Phase (alive only), Byar's formula `f > 0.66 ? 1 : f > 0.33 ? 2 : 3`. On change: `scene.onBossPhase(this, ph)`;
     ph 2 → `pendingFear = true`; ph 3 → `pendingSplit = true`; `cool = 0` if in `approach`/`wait`.
  3. Timers: `nextBlink -= dt; forceLungeT -= dt; lungeAt -= dt; if (resplitT > 0 && (resplitT -= dt) <= 0 && phase === 3) pendingSplit = true`.
  4. `tickFear(dt)` then `tickLook(dt)` (§3.5). Both run in every state, including `defeated`.
  5. Own states (`st += dt; cool -= dt; shudder` like Byar `:206`), then `switch`:
     - `intro` (anim `intro`): done → `approach`, `introDone = true`, `cool = 1.0`.
     - `attack`: Byar's two-hit `attacking` (`src/whitecloaks.js:244-251`); last active frame uses `{...a, ...FADE.thrust}`.
     - `lunge`: `lungeTick(this, dt, FADE.lunge.hit)` (§3.4).
     - `blinkout` (anim): done → `state = 'sunk'`, `st = 0`, `pool = { ...poolSpot(R, s.bounds), t: 0 }`,
       `pool.fx = s.kit?.shadowPool?.(pool)`, `sfx.shadowWhoosh?.()`.
     - `sunk`: `pool.t += dt`; at `st ≥ poolWarn`: `x = pool.x; y = pool.y; face(sign(R.x - x))`,
       `s.kit?.shadowPoolEnd?.(pool)`, `pool = null`, `setState('blinkin', 'blinkin')`.
     - `blinkin`: done → `startAttack()` (rises and slashes; bypasses the token check).
     - `fear` (anim): at `fi ≥ auraFrame` and `!auraOn` → `auraOn = true`, `bump(s,'fears')`,
       `s.kit?.hint?.('fear', 'FEAR AURA! FIRE OR LIGHTNING DRIVES IT BACK')`. Done → `approach`, `cool = rand(0.4, 0.8)`.
     - `split` (anim): done → `makeCopies()`, `approach`, `cool = 0.6`.
     - `stagger` (anim, then holds its last frame): `st ≥ counter.stagger` → `approach`, `cool = rand(0.3, 0.6)`.
     - `defeated`: anim done and `!melting` → `melting = true`, `s.kit?.shadowBurst?.(x, y)`. While melting:
       `meltT += dt`, `a = max(0, 1 - meltT / FADE.melt)`, sprite + shadow alpha `a`; `a === 0` → `gone = true`.
     - otherwise `super.update(dt)`.
- `think(dt)`: return if `entering`. `!introDone` → `setState('intro','intro')`, `say('fade_intro_01')` is
  `startBoss`'s job, return. If `forceLungeT > 0 && R.alive` → `startLunge()`. If `cool ≤ 0 && R.alive && R.state !== 'down'`:
  `pendingFear` → `startFear()`; `pendingSplit` → `startSplit()`; `nextBlink ≤ 0 && !copies.length` → `startBlink()`;
  phase 3 `lungeAt ≤ 0` → `startLunge()`; `adx ∈ range && ady < lane && tokens < max && Math.random() < chance` →
  `startLunge()`. Else `super.think(dt)` (slash via `startAttack`).
- `startAttack()`: Byar's (`:242`). `startLunge()`: face Riley, `setState('lunge','lunge')`, `forceLungeT = 0`,
  `lungeAt = rand(...split.relunge)`, `hitIds.clear()`, `s.kit?.glint?.(x - facing*60, y - 220, 0xffffff)`, `sfx.glint()`.
- `startBlink()`: `setState('blinkout','blinkout')`, `nextBlink = rand(...(phase === 1 ? every : everyP2))`, `bump(s,'blinks')`.
- `startFear()`: `pendingFear = false`, `setState('fear','fear')`. `startSplit()`: `pendingSplit = false`, `setState('split','split')`.
- `makeCopies()`: `side = sign(x - R.x) || 1`; spots `[R.x - side*spread[0], R.x + side*spread[1]]`, each clamped to
  `[bounds.l + 80, bounds.r - 80]`, `y = clamp(R.y ± 30, LANE_TOP, LANE_BOT)`. `new FadeCopy(s, x, y, this)` ×2, pushed
  to `s.enemies` and `this.copies`. Shuffle `split.order` with `Math.random` and assign `lungeAt` to [real, c1, c2].
  `bump(s,'splits')`, `s.kit?.hint?.('copies', 'ONLY THE REAL ONE CASTS A SHADOW')`.
- `inParry()`: `phase === 3 && ((state === 'lunge' && fi <= 2) || (state === 'attack' && fi <= 4))`.
- `takeHit(h, from)` (any source counts; power hits arrive with a plain `src`, `src/stage1.js:360`):
  1. `if (!canBeHit) return false`.
  2. `blinkin` with `fi ∈ counterFrames`, or `inParry()` → `counterHit(h, from)`: `hp -= dmg * counter.mul`,
     `shudder = 0.12`, `setState('stagger','stagger')`, `vx = 0`, `bump(s, inParry ? 'parries' : 'counters')`,
     `s.kit?.hint?.('counter','COUNTER!')`. If parry: `clearCopies(false)`, `resplitT = rand(...split.every)`.
     `hp ≤ 0` → `die`. Return `true`.
  3. `stagger` → `hp -= dmg * counter.mul` (no state change), `die` at 0, return `true`.
  4. `['blinkout','blinkin','fear','split','intro'].includes(state) || wake > 0` → Byar's ×0.6 branch (`:273-275`).
  5. `return super.takeHit(h, from)`.
- `die(dir, h)` (never `knockdown`): `heldBy = null; alive = false; hitsTaken = 0; vx = dir * 60;`
  `clearAbilities(); setState('defeated','defeated'); s.onEnemyDie(this)`.
- `clearAbilities()`: `clearCopies(false)`; `if (pool) { s.kit?.shadowPoolEnd?.(pool); pool = null; }`;
  `auraOn = false; fear = 0; pendingFear = pendingSplit = false; resplitT = 0`.
- `clearCopies(popped)`: for each live copy → `c.vanish(popped)`; `copies = []`.
- `onCopyPopped(c)`: remove from `copies`, `forceLungeT = split.wrongHitPunish`, `bump(s,'copiesPopped')`.
- `sync()`: `super.sync()`; in `sunk` set sprite and shadow alpha 0. `physics(dt)`: skip while `sunk`.
- Never use `scene.time.delayedCall` in this file (restart safety).

### 3.4 Lunge (shared by real and copy): `function lungeTick(e, dt, hit)`
Frame 0 (380 ms) is the telegraph: no motion. Frames 1–2: `e.x += e.facing * FADE.lunge.speed * dt` and
`e.scene.resolveAttack(e, hit)`. Wall (`x ≤ b.l + 60 || x ≥ b.r - 60`) stops motion. `e.done` → `approach`,
`e.cool = rand(...e.T.cool)`.

### 3.5 Fear (methods on Myrddraal)
- `get auraActive()` → `auraOn && dispelT <= 0 && alive`.
- `tickFear(dt)`: if `auraOn` and `lightNear(s, x, fear.dispelRange)`: if `dispelT <= 0` → `bump(s,'dispels')`,
  `s.kit?.hint?.('dispel', 'LIGHT DRIVES THE SHADOW BACK!')`; `dispelT = fear.dispel`. Else `dispelT = max(0, dispelT - dt)`.
  Meter: `inside = auraActive && R.alive && hypot(R.x - x, R.y - y) <= radius`; `fear = clamp(fear ± dt / fill, 0, 1)`.
  When `fear >= 1` and `R.vulnerable && R.z <= 0 && !R.grabbedBy && !['hurt','down','getup','balefire','grabbed','escape'].includes(R.state)`:
  `R.setState('hurt','hurt', fear.hurtMs / (fear.shaken * 1000))`, `R.vx = 0`, `fear = 0`, `bump(s,'shaken')`. No damage.
- `tickLook(dt)`: `auraK` moves toward `auraActive ? 1 : 0` at `1/rampIn` up, `1/rampOut` down. Then
  `if (s.vignette) s.vignette.strength = vig[0] + (vig[1]-vig[0]) * auraK + (calmMotion() ? 0 : pulse * auraK * Math.sin(t * 4))`.
  For each `L` of `s.fires`: `L.baseR ??= L.radius; L.radius = L.baseR * (1 - (1 - torchDim) * auraK)`. Adds no lights.
  `s.vignette` is `null` with `?vig=0` or after `dropVignette()`: skip silently.

## 5. Edge cases
- **Riley at a wall:** `poolSpot` flips to his front, never outside `bounds ± 70`.
- **Blink during a lunge/copies:** blinks only start from `think` and never while copies live.
- **Token cap:** `forceLungeT` and `blinkin → startAttack` bypass tokens (bounded: one boss). Copies obey them.
- **Riley dead / respawning / game over:** `fear` decays (not `R.alive`); shaken needs `R.vulnerable`.
- **Pause / hitstop:** `update` is not called; every timer is `dt`-driven, so all freeze.
- **Victory mid-split / mid-blink / mid-fear:** `die` → `clearAbilities`; `tickLook` keeps ramping `auraK` to 0, so the
  vignette ends at exactly 0.35 and every torch at `baseR`.
- **Restart:** Phaser shutdown destroys sprites and lights; no module-level state, no `delayedCall` in this file.
- **Light budget (§2.5):** the Fade adds no lights; dimming changes radii only.
- **Boss bar:** the HUD fades on `state === 'defeated'` (`src/hud.js:244`), so the melt stays in `defeated` with
  `melting = true` instead of a separate `melt` state.
