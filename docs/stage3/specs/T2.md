## 2. Path decision (approved by Jason; this changes PLAN.md's paths)

`tests/assets.test.mjs:7-9` (existing, must not be edited) asserts `audit().preFight.inventoryUpperBoundBytes ≤
25_000_000`. `tools/audit-stage1.mjs:45-55` sums **every file** in `assets/{chars,bg,props,ui,powers}`, plus `src/*.js`
and the voices. After T1 that total is about **24,907,665 bytes**, which leaves **≈92 KB** of headroom. Placeholder
atlases (and later real art: zealot-0 alone is 1.03 MB) in `assets/chars`, `assets/props` or `assets/ui` would
break that test.

So **all Stage 3 art lives outside the audited directories**:

| PLAN.md path | T2 path |
|---|---|
| `assets/chars/{cutthroat,fade,riley3}*` | `assets/stage3/chars/…` (same filenames) |
| `assets/props/{prop-rooftiles,fx-shadowpool,fx-shadowburst,fx-fade-far}.webp` | `assets/stage3/props/…` |
| `assets/ui/fade-portrait.webp` | `assets/stage3/ui/fade-portrait.webp` |
| `assets/bg3/*`, `assets/story/story3_panel_{1,2,3}.jpg` | unchanged (not audited) |
| `assets/stage3/ART_STATUS.json` | unchanged |

Each Stage 3 `anims.json` carries `"dir": "assets/stage3/chars"`. `src/assets.js:10,18-19` hard-codes
`assets/chars/`, so the first task that loads these atlases (T3's `queueStage3` or T4) must load `<k>.A` from

T1 code that still assumes `assets/chars/` for Stage 3 chars: `src/assets.js:10,14` and

## 5. `tools/stage3/make_placeholders.py` (dev-time only)

- **Header docstring:** the same disclaimer as `tools/make-power-placeholders.py:2-6` ("These are not art…").
- **Libraries:** stdlib plus Pillow only. Copy (do not import) the `dashed` (`:15`) and `centred` (`:22`) helpers.
- **CLI:** `python3 tools/stage3/make_placeholders.py [--out DIR] [--check]`. Default `DIR` is the repo root; every
  manifest path is relative to `DIR`.
  - **Overwrite guard:** when `DIR` is the repo root and `assets/stage3/ART_STATUS.json` exists, skip every output
    whose entry has `placeholder: false`. Copy those entries unchanged into the new `ART_STATUS.json`. With `--out`,
    write everything.
  - **`--check`** (writes nothing in the repo): generate twice into two temp dirs, then assert (a) both runs are
    byte-identical, (b) every `placeholder: true` file in the repo is byte-identical to the temp copy and to its
    `sha256` in `ART_STATUS.json`, (c) every `_n`/`_nl`/normal image decodes (Pillow) to exactly one colour,
    `(128,128,255)` / `(127,128,255)`. Print `OK <n> files` or exit non-zero listing mismatches.
- **Determinism**
  - No timestamps or random numbers. Iterate in manifest order.
  - Write JSON with `json.dumps(obj, indent=1, ensure_ascii=False) + "\n"`. Atlas page JSON uses the compact
    single-line form, like `assets/chars/zealot-0.json`.
  - Save WebP as `lossless=True, quality=0, method=0`. Save JPEG as `quality=80, optimize=False`.
  - `_n` / `_nl` / normal images are mode `RGB`.
  - If the font file is missing, exit non-zero. Never fall back to another font.
- **Rounding:** `R(v) = int(v + 0.5)`. This equals JS `Math.round` for v > 0, as used by
  `tests/assets-geometry.test.mjs:29` and `tests/stage2-assets.test.mjs:22` (`Math.round(canvas*scale)`).

**Characters**, per char, with `fw, fh = R(canvas[0]*scale), R(canvas[1]*scale)`:
1. **Frame names**, in sheet order: `<key>_<anim>_<nn>` with `nn` = 2 digits from 00. For example `cutthroat_walk_00`
   and `riley3_grabbed_00`. **Anim names** are `<prefix><anim>`, for example `riley_grabbed` (§2.4).
2. **Packing**, per page, frames in order: `cols = min(n, (4096+gap)//(fw+gap))`, `rows = ceil(n/cols)`,
   page `W = cols*(fw+gap)-gap`, `H = rows*(fh+gap)-gap`. Assert `W, H ≤ 4096`. Expected:

   | Page | Frame | Count | Page size |
   |---|---|---|---|
   | cutthroat-0 | 558×372 | 40 | 3918×2242 |
   | riley3-0 | 816×544 | 8 | 4088×1090 |
   | fade-0 | 660×420 | 32 | 3970×2530 |
   | fade-1 | 660×420 | 24 | 3970×1686 |

3. **Frame drawing** (RGBA, transparent background)
   - Silhouette box: `R(silhouette*scale)`, centred at `x = R(anchorX*fw)`, bottom on `by = R(baseline*scale)`. Fill
     `(110,110,124,170)` with a dashed outline `(235,235,245)`.
   - A red `(255,90,90)` baseline line across the full frame at `by`, and a 1 px vertical anchor line.
   - A facing arrow pointing left for `native: -1` and right for `native: 1`.
   - Text centred in the box: `PLACEHOLDER` / `<key>_<anim>` / `<nn>  <hold> ms`. Start at 16 px and step the size down
     until the widest line fits the box width minus 8 px, with a minimum of 8 px.
4. **Page JSON:** `{"frames": {name: {"frame": {x,y,w:fw,h:fh}, "rotated": false, "trimmed": false,
   "spriteSourceSize": {"x":0,"y":0,"w":fw,"h":fh}, "sourceSize": {"w":fw,"h":fh}}}, "meta": {"image": "<page>.webp",
   "size": {"w":W,"h":H}, "scale": 1}}`.
5. **Normal maps:** `<page>_n.webp` is W×H flat `(128,128,255)`. `<page>_nl.webp` is W×H flat `(127,128,255)`, the
   red channel inverted, per the `src/assets.js:1-3` convention.
6. **`<key>.anims.json`:** keys in this order: `key`, `canvas`, `baseline`, `scale`, `pages`
   (`["<key>-0", …]`), `placeholder: true`, `dir`, `anims`. Each anim is `{name, frames, holds, loop, pages}`, the
   same shape as `assets/chars/zealot.anims.json`. `notes` from the manifest are **not** copied.

**Images**
- `far` and `panel`: opaque RGB `(24,26,34)`, a dashed border and centred lines:
  `PLACEHOLDER PAINTING` / `<file basename>  <w>x<h>` / (`caption` or id).
- `mid`: RGBA.
  - Rows `y < 360` are transparent (sky). Below that, fill `(40,44,58,255)`.
  - A vertical dashed divider at x = 1086, and each half labelled with its `halves` text.
  - The `_n` is flat RGB `(128,128,255)`.
- `floor`: opaque fill with no border (the tile must stay seamless), a centred label, and a flat `_n`.
- `strip`: frames are `size[0]/frames` px wide. Draw the same frame card as `card(... frames=n)`
  (`make-power-placeholders.py:28`), with `frame i` on each.
- `portrait`: opaque `(40,20,48)` with a centred circle outline and `PLACEHOLDER` / `fade-portrait`.

**Prompts → `docs/stage3/prompts/<id>.json`**
- Shape: `{"id", "tool": "chatgpt", "fallback": "gemini", "tries": 0, "attach": [...], "output": "...", "prompts": [text]}`.
- `text` is the fenced block under the `#### ` heading whose backticked id matches, read verbatim from
  `docs/stage3/PLAN.md` §4.2.
- Floors: the single block is shared by all three ids. Keep the common lines, keep only the line that starts with
  `[<id>]`, and strip that tag.
- If any id is not found, exit non-zero.

## 7. Edge cases

- **Float rounding:** compute `600*0.62` and `1100*0.6` with `R()`. Never use Python `round()`, which rounds half to even.
- **Name collision:** `riley3` frame names must not reuse `riley_*` frame names, even though they are on separate
  textures. This keeps `releaseChars` (`assets.js:36-41`) and `NML` clean.
- **Partial real art (T14):** the guard in §5 stops a rerun from clobbering painted files. A char page that mixes
  real and placeholder sheets is packed by T14's `pack.py`, not by this script.
- **Floor seams:** draw no border or edge text on floors.
- **Mid plates:** the sky must stay truly transparent (alpha 0).
- **Text:** keep it ASCII except the `'` in QUEEN'S. DejaVu covers that.
- **Pillow drift:** another Pillow may encode other bytes; `--check` (b) then fails. Regenerate, re-commit with fresh
  `sha256`, and note the Pillow version in the commit message.
- **Size:** placeholder pages are small (flat/transparent) and outside the 25 MB audit (§2) either way.
