  `releaseStage(n)`, `resolveStage` with the `s3` flag.

  atlases under `assets/stage3/chars/` with `"dir"` in each `anims.json` (T2 §2).

### 3.2 Pure helpers
- `export function lerpColor(a, b, u)`: per channel `Math.round(ca + (cb - ca) * u)`, packed back to `0xRRGGBB`.
- `export function timeOfDay(camX, keys)`. `keys` is `lights.json.timeKeys`: `[{ x, ambient, farMix, sunI }]`, with x
  strictly increasing. Behaviour:
  - Empty or missing `keys` → `{ ...TOD_FALLBACK }`. One key → that key's values with `t: 0`.
  - `x0 = keys[0].x`, `x1 = keys.at(-1).x`, `t = clamp((camX - x0) / (x1 - x0), 0, 1)`.
  - Find segment `i` with `keys[i].x ≤ camX ≤ keys[i+1].x`; clamp to the first or last key outside the range.
    `u = (camX - keys[i].x) / (keys[i+1].x - keys[i].x)`.
  - `ambient = lerpColor(hex(k0.ambient), hex(k1.ambient), u)`; `farMix` and `sunI` are linear lerps.
  - `torchK = t` (the ignite threshold: a torch is lit once `litAt ≤ torchK`).
  - Returns a fresh object `{ t, ambient, farMix, sunI, torchK }`. No Phaser and no scene access.

### 3.4 `class Stage3Kit extends Stage2Kit`
Extending keeps every Whitecloak hook working (`src/whitecloaks.js:49,98,131-139,151-180` call `kit?.koStars`,
`telegraph`, `onBlock`, `onGuardBreak`, `claimMudJoke`, `fireArrow`, `loseSkyArrow`, `archerBusy`, `markSky`), plus
`glint`, `hint`, `koStars`, the ribbon and `clearHazards`, without editing `stage2.js`. T7 later replaces the ribbon
with its mixin.

- `constructor(s)`: `super(s)`, then `this.cfg = s.cache.json.get('lights3') || {}`,
  `this.plates = s.cache.json.get('plates3') || {}`, `this.keys = this.cfg.timeKeys || []`,
  `this.tod = timeOfDay(s.camX || 0, this.keys)`, `this.torchSpots = []`, `this.lit = []`, `this.sun = null`,
  `this.sunGone = false`, `this.emitters = []`, `this.nightLayer = null`, `this.dayStopped = false`, and
  `Object.assign(this.stats, { torchesLit: 0, sunRemoved: 0 })`.
- `get ambient()` → `timeOfDay(this.s.camX || 0, this.keys).ambient`. `get ambientUnlit()` →
  `hex(this.cfg.ambientUnlit) || 0x5a6482`. `create()` reads both through `setBackdropLit`
  (`src/stage1.js:195`).
- `claimMudJoke()` → `false`. The mud joke is Stage 2 only.
- `build()`, in this order:
  1. `this.makeTextures()` (inherited: `raindrop`, `lanemark`, `ring`).
  2. **Far plates.** `far3d` at depth -100 and `far3n` at depth -99. Both use origin (0,0), scroll factor
     `P.farScroll ?? 0.12` and the scale formula of `src/stage2.js:54`, with **no tint**. Set `farNight.setAlpha(tod.farMix)`.
  3. **Mid plates.** Copy `src/stage2.js:55-59` with keys `['mid3a', 'mid3b']`, using `P.midScale`, `P.midParallax`,
     `P.midX0` and `P.overlap`. Push them to `s.midPlates` and `s.backdropLit`.
  4. **Floors** from `P.floors = [{ key, from, to }]`, with `fh = VH - LANE_TOP + 64`, `fy = LANE_TOP - 64` and
     `ts_i = fh / source height`. Floor `i` is a tileSprite at `(from, fy)`, width `to - from + (i < last ? 200 : 0)`,
     depth `-40 + i`, lit. For `i > 0`, add a seam tileSprite at `(from - 200, fy)` of width 200 with key `i`,
     `setTilePosition(-200 / ts_i, 0)`, alpha 0.5 and depth `-40 + i`, exactly like `src/stage2.js:65`. Push all of
     them to `s.backdropLit`.
  5. **Lights.** Set `s.moon = null` and `s.fires = []`. Set `s.fireCap = this.cfg.capOnScreen || 4`
     **unconditionally**, so a Stage 2 rage cap of 5 cannot leak in (S8). Precompute `torchSpots` from
     `cfg.torches` (`[plate, px, py, I, radius, litAt]`) with the world-position formula of `src/stage2.js:77`
     (`wx = m.x + px*ms`, `wy = MID_Y - m.height*ms + py*ms`). No light is created yet.
  6. **Sun.** If `cfg.sun` exists and `tod.sunI > 0`, create
     `this.sun = s.lights.addLight(s.camX + sun.sx, sun.sy, sun.radius, hex(sun.color), sun.I * tod.sunI, 200)`.
  7. **Particles** (`cfg.atmos`):
     - The day back layer `this.motes` uses `flake` with scroll factor 0, depth -45 and tint `atmos.day.tint`.
     - The front layer `s.snowFront` uses `flake` with depth 5000, scroll factor 0 and `atmos.front.frequency`. The
       governor (`src/main.js:45`) thins this layer, so it must exist after `build()`.
     - Push `{ em: this.motes, base: atmos.day.frequency, thin: atmos.day.thin }` to `this.emitters`.
  8. `this.update(0)`, so torches with `litAt ≤ t` (for example `?skip=boss`) ignite on the first frame.
- `start()`: `preloadClips(STAGE3_VOICES)`. No rain. `destroy()`: no-op. Do **not** call `setRain`.
- `update(dt)`. Stage 1 calls it before `updateCamera` (`src/stage1.js:680,683`), so it uses `s.camX`.
  1. `const tod = this.tod = timeOfDay(s.camX, this.keys)`.
  2. **Ambient.** `s.ambient = s.backdropIsLit === false ? this.ambientUnlit : tod.ambient`. Then
     `if (s.lightsOn !== false) s.lights.setAmbientColor(s.ambient)`. The Digit1 lights-off toggle stays white.
  3. `this.farNight.setAlpha(tod.farMix)`.
  4. **Sun.** If `this.sun` exists: when `tod.sunI <= 0`, call `s.lights.removeLight(this.sun)`, set
     `this.sun = null`, `this.sunGone = true` and `this.stats.sunRemoved++`. Otherwise set
     `sun.x = s.camX + cfg.sun.sx` and `sun.intensity = s.lightsOn ? cfg.sun.I * tod.sunI : 0`. The sun is never
     re-added in the same run.
  5. **Torches.** For each spot with `!spot.L && spot.litAt <= tod.torchK`, ignite it:
     - `L = s.lights.addLight(wx, wy, radius, hex(cfg.torchColor) || 0xff9a48, 0.01, 110)`.
     - Set `L.baseX = wx`, `L.baseI = 0.01`, `L.seed = Math.random() * 10` and `L.par = midParallax`.
     - Push `L` to `s.fires`, set `spot.L = L` and `spot.age = 0`, and add a halo exactly like
       `src/stage2.js:79`.
     - Call `sfx.torchIgnite?.()` (T8 adds it) and `this.stats.torchesLit++`.

     **Every frame, for each lit spot:** `age += dt`. The ramp factor is `k = age < TORCH_RAMP ? TORCH_FLARE * age / TORCH_RAMP`
     `: Math.max(1, TORCH_FLARE - (TORCH_FLARE - 1) * (age - TORCH_RAMP) / TORCH_SETTLE)`. Set `L.baseI = I * k`.
     `Stage1.update` (`:643`) applies the flicker, and `placeFires` (`:699`) applies the cap. Unlit spots own no
     light, so they never use cap slots or the §2.5 budget.
  6. **Night layer.** When `tod.farMix >= atmos.nightFrom` and there is no night layer yet, create
     `this.nightLayer`. It uses `ember`, ADD blend, scroll factor 0, depth -45, a slow rise and `atmos.night.tint`.
     Its starting frequency is `s.fx.quality >= 2 ? thin : base`. Push it to `this.emitters`. When
     `tod.farMix >= 1` and `!this.dayStopped`, call `this.motes.stop()` and set `this.dayStopped = true`.
  7. **Thinning (S9).** For each emitter entry, `f = s.fx.quality >= 2 ? thin : base`. If `em.frequency !== f`,
     set `em.frequency = f`. `s.snowFront` is not in this list because the governor owns it.
  8. Inherited per-frame work for archers and KO stars: `this.updateArrows(dt, R)`, `this.updateSky(dt, R)`,
     `this.updateStars(dt)` and `this.updateSticks(dt)`. Do **not** call lightning, volley, torches (Byar's thrown
     torches), beams or barn.
- `onZoneClear(i)`: no-op (T7 adds the glimpse). `threats()`: `{ arrows, sky }` for now (T7 extends it).
  `clearHazards()`: inherited.

## 6. Edge cases

- **Restart in Stage 3.** Phaser's shutdown clears lights and objects, and `create()` builds a new kit. Sun, torch
  latches and emitters are all per kit instance. Never cache any of them on the module.
- **`?skip=boss`.** `camX` starts at the T1 Stage 3 `skipBoss.camX`. `build()` must not add the sun when
  `tod.sunI ≤ 0`, and `update(0)` ignites the torches with no ramp skip (they flare in over 0.4 s).
- **`?lit=0` and governor level 4.** `setBackdropLit(false)` sets the ambient to `ambientUnlit` once. `update` must
  keep it there, not overwrite it with `tod.ambient`.
- **Lights off (Digit1).** Ambient stays white and the sun intensity goes to 0. Fire intensity is already zeroed by
  `Stage1.update`.
- **Pause and hit-stop.** `update` is not called, so the ramps freeze. That is correct.
- **Missing JSON** (the headless helper has no `plates3` or `lights3`). The kit must still build: no torches, no sun,
  `TOD_FALLBACK` ambient, cap 4. If `P.floors` is missing, use one floor `floor3a` from 0 to `WORLD_W`.
- **Rounding.** Every timeKey channel is non-increasing (dusk is `0x3a3a52`, not PLAN's `0x3a3a58`). That keeps the
  rounded luminance exactly monotone.
- **Light budget.** At most 4 torch lights are visible. The sun is gone by the boss zone, and unlit torches have no
  light. T7 asserts the worst case.

## 9. Discrepancies with PLAN.md and open questions

1. **Night key x.** PLAN's example puts night at x 4000, but the boss camera is locked at `camX` 3920
   (`zone.r - VW`). The spec uses 3900 so the sun reaches 0 and is removed in the boss zone (PLAN test 3).
2. **Dusk colour.** PLAN's `0x3a3a58` has a blue channel above the sunset value (`0x52`), which can break exact
   monotonic luminance after rounding. The spec uses `0x3a3a52`.
3. **`timeKeys` shape.** Each key carries `farMix` and `sunI` along with `ambient`, so everything is data-driven.
   `torchK` is defined as `t`, because PLAN does not define it.
4. **Kit reuse.** `Stage3Kit extends Stage2Kit`. Stage 3 waves contain zealots and archers, whose hooks are not all
   `?.`-guarded at the method level (for example `s.kit?.archerBusy(this)`), so a bare kit would throw.
5. **S8 fix scope.** Only the Stage 3 kit resets `fireCap`. Resetting it in `create()` for every stage, as the review
   proposes, would change the Stage 1 behaviour after a Stage 2 rage. Left for Jason or T15.
6. **Atlas loading lives in T3.** T2 §2 hands the `m.dir` loader change to "T3 or T4". It is in T3, so T4, T5 and T6
   must not duplicate it. T11's `stage-query-probe` stubs `load.on` as a no-op, so its probe will not see the
   atlas pages.
7. **T1 coupling.** If T1's test 5 asserts a literal released-key list for "load 3 after 2", adding `arrow` and
   `ribbon` to `STAGE_TEXTURES[3]` changes which keys are shared. T1 should compute the expected set from the data.
   Open question: is the registry wiring for Stage 3 in `stage1.js` (assumed) or somewhere else?
